# Tarefas do Projeto - Brigada Popular

- [ ] **Tarefa 1:** Criar conta no Supabase, iniciar novo projeto e rodar o `schema.sql` no SQL Editor.
- [ ] **Tarefa 2:** Criar o arquivo `design.md` (definir cores de luta/populares, ex: vermelho, preto, branco, e fontes legíveis).
- [ ] **Tarefa 3:** Criar a interface básica em HTML/CSS (`index.html` e `style.css`) contendo o formulário e a lista vazia.
- [ ] **Tarefa 4:** Criar o script `app.js` para conectar com o Supabase:
    - 4.1. Função para capturar os dados do formulário e salvar no banco.
    - 4.2. Função para buscar os chamados do banco e renderizar na tela.
- [ ] **Tarefa 5:** Subir os arquivos para um repositório no GitHub.
- [ ] **Tarefa 6:** Ativar o GitHub Pages para publicar o site.
